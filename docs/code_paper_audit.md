## What is now explained

1. Archived validation folder names reverse their contents. Count/name/shape agreement did not validate semantic roles. This is an archive/data-layout conflict; the runtime paths in the original text source differ, so it is not proof that original training used the reversed pairs.
2. Historical 90/30 is real source history, supported by archive CRCs and cached code. The recent 80/20 reconstruction has different HOG and coordinate/geometry details; changing only historical parameters does not create that implementation.
3. HOG library choice materially changes P48 correspondences and error. Coordinate rounding makes smaller changes in the tested examples. Similarity refitting and control-point dtype do not explain their observed large discrepancy.
4. The recovered bootstrap script's center is definitively a point estimate. The new diagnostic separates point, mean and percentile CI without altering source sampling or published values.
5. Historical full-model and weights-only artifacts are numerically identical for all 48 learned weight arrays. Their architecture and 24,000 optimizer steps match the recovered TensorFlow model family, not later 512 px PyTorch/BCE variants.

## Still unresolved

Exact sigma 5 / vessel-edge constrained label generation; provider-mask lineage and split seed; the training runtime's actual validation directories; published Fig. 9 numerical logs; original version for the published 80/20 settings; full Table 1 aggregation and bin policy; S rounding; publication bootstrap-mean source. MIT approval was completed on 2026-10-29; separate authorization for commit/publication remains required.

Main Overall AUC **0.626** and reported bootstrap mean Overall AUC **0.628** remain separate paper quantities. No result was adjusted to force either value. The minimized main code is a clearly identified recovered reconstruction that runs; it is not represented as the historical published implementation.
